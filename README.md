# Бот для звука из видео

Присылаешь ссылку — получаешь mp3. Бот забирает только аудиодорожку, режет рекламные вставки
через SponsorBlock, отдаёт файл в чат.

## Что умеет

- ссылки с YouTube, Rutube, VK, Vimeo, SoundCloud и ещё сотен площадок — всё, что поддерживает `yt-dlp`;
- mp3 192 kbps с тегами (название, исполнитель);
- ограничения по длине и размеру, чтобы не упереться в лимиты Telegram;
- понятные ошибки: закрытое видео, слишком длинное, файл больше 48 МБ.

## Запуск

```bash
# 1. ffmpeg обязателен: без него не собрать mp3
brew install ffmpeg        # macOS
sudo apt install ffmpeg    # Debian/Ubuntu

# 2. зависимости
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. токен и запуск
export BOT_TOKEN="токен из @BotFather"
python3 bot.py
```

## Ограничения

| Что | Значение |
|---|---|
| Длина видео | до 40 минут |
| Размер файла | до 48 МБ (лимит Telegram — 50) |
| Плейлисты | не поддерживаются, только одиночные ссылки |
| Приватные видео | не скачиваются |

## Структура

```
bot.py            хендлеры, скачивание через yt-dlp, отправка файла
requirements.txt  aiogram 3, yt-dlp
.env.example      переменные окружения
```

## Важно

Бот не обходит закрытый доступ и платный контент. Скачивайте только то, что имеете право
скачивать: своё, чужое с разрешения или по свободной лицензии.
